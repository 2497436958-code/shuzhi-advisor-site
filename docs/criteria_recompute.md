## 打分规则

| 题型 | 规则 |
|---|---|
| 3 选项单选 | `0 / 50 / 100` |
| 5 选项单选 | `0 / 25 / 50 / 75 / 100` |
| 6 选项单选 | 官方分值口径未覆盖，按等距线性兜底：`选项序号 ÷ 5 × 100`，并显式披露 |
| 多选「无」 | `0` |
| 多选非「无」 | `选中数 × 100 ÷ (总选项数 - 1)` |

得分点公式：

```text
points = chain_weight × score
```

说明：`chain_weight` 是一级、二级、三级权重连乘后的百分制权重，例如采集项 1 的 `0.08` 对应满分 8 分。

### 需要准备的数据

1. 企业名称或匿名编号。
2. 15 个采集项答案。
3. 16 个应用场景等级。
4. 如果有公开评测结论，附公开结论的来源和日期。
5. 数据来源必须标注：真实 / 合成 / 推算 / 待核实。

### 复算入口

```bash
python3 scripts/recompute_profile.py path/to/profile.json
```

如果输入文件是预计算 payload，则使用：

```bash
python3 scripts/recompute_profile.py path/to/payload.json --payload
```
